# 📅 Home Office Schedule Generator

## Description
This program generates a remote work (Home Office) schedule for employees on specific weekdays. It takes into account restrictions such as certain employees having on-site obligations.

---

## Features 🚀
- Automatically assigns employees to specific weekdays.
- Handles constraints (e.g., some employees have on-site duties on certain days).
- Randomly distributes employees to avoid working two consecutive days.

---

## Participants 👥
- **`o1`**: Works only on Tuesday and Wednesday (on-site duty at 6:00 AM).
- **`o2`**: Works only on Thursday (on-site duty at 6:00 AM).
- **`os3`, `os4`**: Available on all days.

---

## Days of Home Office 🗓️
- Tuesday
- Wednesday
- Thursday

## How It Works? 🛠️
1. The program defines a list of employees and Home Office days.
2. It sets restrictions for employees with on-site obligations.
3. It randomly assigns the remaining employees to days while avoiding conflicts.
4. Displays the final schedule.

---

## Requirements 📋
- Python 3.x
- `random` library (included by default in Python)

---
